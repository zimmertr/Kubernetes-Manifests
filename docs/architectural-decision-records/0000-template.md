# NNNN. The decision, as one sentence

- Status: Accepted
- Date: YYYY-MM-DD, the day it was decided. When nothing records the day, the merge date of the PR that shipped it, and say that git is the source.
- Decider: who decided. When nothing records who, the author of that PR, and say that git is the source.
- Issues and PRs: #N, #M, and Kubernetes-Manifests PRs as KM#N
- Cited in code as: the issue and PR numbers that source comments cite for this decision, or "none"
- Guide: [`CLAUDE.md`](../../CLAUDE.md), the section or bullet that states the rule today

## Context

What forced a choice. Keep it to one short paragraph.

## Decision

What was chosen, stated so a reader can check the code against it.

## Evidence

The measurements and observations that settled it, each with the date it was taken. "No dated measurement" when there were none.

## Alternatives rejected

Each option that was tried or considered, and why it lost. An earlier decision that this one reversed goes here too.

## Consequences

What holds the decision in place (a test, a CI check, a manifest), and what it costs.
