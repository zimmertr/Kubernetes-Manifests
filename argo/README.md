## Summary

Argo is a collection of Argo Applications: Argo CD, Argo Rollouts, and Argo Workflows. Argo CD is installed by hand at first and then manages itself, along with everything else in this repository. See the [Argo CD](../README.md#argo-cd) instructions in the main README to bootstrap it.
